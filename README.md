# 📊 Sales Analysis Dashboard — Power BI

An interactive **Power BI Sales Analysis Dashboard** designed to provide a clear overview of sales performance, profitability, product performance, sales channels, payment methods, and category-level performance.

The dashboard combines KPI cards, trend analysis, categorical comparisons, and interactive filters to help users explore sales data from different perspectives.

## 🎯 Project Objective

The objective of this project is to build an interactive business intelligence dashboard that provides a consolidated view of:

- Overall sales performance
- Sales quantity
- Profitability
- Monthly and daily sales trends
- Sales channel performance
- Payment method distribution
- Product-level sales
- Category-level sales

The dashboard is designed to make important sales and profitability metrics easier to monitor and analyze.

## 📊 Dashboard Features

### 💰 Sales & Profit Analysis

The dashboard provides a monthly view of:

- Total selling value
- Profit
- Monthly sales trends
- Changes in sales performance throughout the year

### 📅 Daily Sales Analysis

The daily sales visualization provides a more granular view of sales fluctuations across the selected period.

### 🛒 Sales Type Analysis

Sales are analyzed across different sales channels:

- Direct Sales
- Online
- Wholesaler

This allows comparison of how different sales channels contribute to overall sales.

### 💳 Payment Type Analysis

The dashboard compares sales based on payment method:

- Online
- Cash

### 🏷️ Product Analysis

The product-level visualization highlights sales generated by individual products and makes it easier to identify higher-performing products.

### 🗂️ Category Analysis

Sales are also broken down by product category, including categories such as:

- Personal Care
- Household
- Beverages
- Grocery
- Furnishing

### 🔎 Interactive Filters

Users can interact with the dashboard using filters for:

- Year
- Month
- Sales Type
- Payment Mode

These filters allow users to explore different segments of the sales data interactively.
